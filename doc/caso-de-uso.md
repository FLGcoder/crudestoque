    Documentacao de Casos de Uso
    Sistema: Gestao de Estoque de Mercado

     Atores

    - Operador de Estoque / Administrador: Responsavel pelo gerenciamento do estoque do mercado.

     Casos de Uso

   **Cadastrar Produto**
   - **Ator**: Operador de Estoque
   - **Descricao**: Permite inserir um novo produto informando nome, categoria, descricao, preco, quantidade e data de validade.
   - **Pre-condicao**: Preencher todos os campos obrigatorios.

   **Listar Produtos**
   - **Ator**: Operador de Estoque
   - **Descricao**: Exibe a lista com todos os produtos armazenados no banco de dados.

   **Editar Produto**
   - **Ator**: Operador de Estoque
   - **Descricao**: Permite alterar os dados de um produto ja cadastrado.

   **Excluir Produto**
   - **Ator**: Operador de Estoque
   - **Descricao**: Remove um produto do estoque permanentemente apos confirmacao.
